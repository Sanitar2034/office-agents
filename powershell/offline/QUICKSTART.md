# Быстрый старт (офлайн-машина)

Эта папка самодостаточна: собранные аддины (`site/`), локальный Office.js (`office-js/`),
манифесты (`manifests/`) и сервер на чистом PowerShell. Node.js, Python и права
администратора не нужны.

## 1. Установка (один раз)

```powershell
cd <эта-папка>
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Создаёт самоподписанный сертификат localhost для текущего пользователя, делает его
доверенным и регистрирует `manifests\` как доверенный каталог надстроек Office (HKCU).
Если Windows покажет диалог о добавлении сертификата — нажмите «Да». Удаление всего:
`.\uninstall.ps1`.

## 2. Запуск сервера

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1              # сервер
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Launch excel   # сервер + Excel
```

Сервер слушает только localhost: **3000** — Excel, **3001** — PowerPoint, **3002** — Word.
Держите окно сервера открытым, пока работаете с аддинами.

## 3. Добавление надстройки в Office (один раз на приложение)

Word/Excel/PowerPoint → **Вставка → Получить надстройки / My Add-ins → Общая папка
(SHARED FOLDER)** → OpenExcel / OpenPPT / OpenWord → **Добавить**. Откроется панель чата.

## 4. Подключение LLM

Нужен OpenAI-совместимый сервер, доступный по сети или на этой машине
(Ollama / LM Studio / llama.cpp / vLLM).

В настройках аддина (Settings → Custom Endpoint) есть два режима подключения:

**Direct HTTPS** — прямо указываете `https://`-адрес сервера в поле Base URL.
Работает, если сервер под HTTPS с доверенным сертификатом и разрешает CORS
(кнопка «setup notes» в настройках показывает, как включить CORS для vLLM,
llama.cpp, Ollama). Для HTTP-only серверов (Ollama, LM Studio) не подходит.

**Local Proxy** — аддин ходит на свой же origin (`https://localhost:300X/llm-proxy/v1`),
а офлайн-сервер перенаправляет запросы на LLM-бэкенд. Подходит для обычных
HTTP-бэкендов, CORS не нужен. Адрес бэкенда настраивается прямо из настроек
аддина: введите его в поле «LLM backend address» и нажмите Save — сервер
сохранит его в `server-config.json` и начнёт использовать сразу (без перезапуска).
Тот же адрес можно задать и вне аддина:

1. На один запуск: `.\start.ps1 -LlmProxyTarget http://192.168.1.50:11434`
2. Постоянно: в `server-config.json` рядом со скриптами (поле `llmProxyTarget`)

| Приложение  | Base URL (режим Local Proxy)          |
|-------------|---------------------------------------|
| Excel       | `https://localhost:3000/llm-proxy/v1` |
| PowerPoint  | `https://localhost:3001/llm-proxy/v1` |
| Word        | `https://localhost:3002/llm-proxy/v1` |

Модель — развёрнутая на сервере; ключ обычно не нужен. Стриминг токенов
сохраняется в обоих режимах.

## 5. Контекст и сжатие

В настройках аддина (Settings):

- **Context Limit (tokens)** — лимит контекста модели. `0` = брать из каталога модели;
  для локальных моделей каталог часто врёт (подставляется 128k), поэтому укажите
  реальное значение (например 32768 или 8192).
- **Auto-compact Context** — при заполнении контекста на ~80% старые сообщения
  автоматически заменяются сводкой от модели: разговор продолжается без обрыва.
  Лимит и сводка не режут текущую задачу — последние сообщения остаются как есть.

Команда `/compact` в поле ввода чата сжимает контекст вручную в любой момент.
Промпт сжатия следует открытому паттерну Claude Code: сначала анализ диалога,
затем структурированная сводка (намерения, состояние документа, ошибки, все
сообщения пользователя, незавершённые задачи, следующий шаг дословно).

## 6. Скиллы (готовые методики)

Папка `skills\` содержит готовые SKILL.md-методики для агента. Установка в
аддине: **Settings → Skills → загрузить папку** со скиллом (например,
`skills\ifrs16-lease`). После установки описание скилла попадает в системный
промпт, и при подходящем запросе («расчёт аренды по МСФО 16») агент сам
загружает полную методику.

- `ifrs16-lease` — расчёт договора аренды по МСФО (IFRS) 16: четыре листа
  (Параметры / График / ОСВ — сальдо-обороты / Отчётная дата). Базовая модель
  собирается ОДНИМ вызовом eval_officejs с готовым скриптом из скилла —
  подходит малым моделям (4B+); параметры передаются JSON-файлом. Модификации:
  выкуп/лизинг, аванс, стимулы, CPI-индексация, переоценка, малая аренда,
  несколько договоров, rent-free.

## Проверка и типовые проблемы

- `https://localhost:3000/taskpane.html` должен открыться в Edge без предупреждений
  о сертификате. Предупреждение → переустановите доверие: `.\install.ps1`.
- Панель пустая/не открывается → сервер запущен? Каталог добавлен до запуска Office?
  Перезапустите приложение после `install.ps1`.
- В консоли сервера виден каждый запрос (`[время] GET /... [200]`) — 404 значит,
  что-то не скопировалось.
- Запрос к `telemetryservice.firstpartyapps.oaspapps.com` не резолвится — это
  телеметрия Office.js, на работу не влияет.
- «Failed to fetch dynamically imported module …/assets/*.js» — таскпан в Office
  остался от старой сборки, а `site/` уже обновили (хэши файлов меняются при каждой
  пересборке). Перезагрузите аддин: закройте и снова откройте панель, либо
  перезапустите приложение Office. В консоли сервера это видно как
  `[404 STALE ASSET - reload the add-in!]`.
- Требуется Office 2021+/Microsoft 365 (WebView2).
