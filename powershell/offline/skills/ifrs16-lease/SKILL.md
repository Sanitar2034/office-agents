# МСФО (IFRS) 16 — расчёт договора аренды

Строишь модель из **трёх листов** (именно с такими именами — на них ссылаются формулы):
1. `Параметры` — все входные данные и допущения.
2. `График` — расчётный график по периодам.
3. `Отчётная дата` — показатели на выбранную пользователем дату.

Жёсткие правила:
- Каждое допущение — в отдельной ячейке `Параметры`; все производные числа — формулами, ссылающимися на эти ячейки. Никаких вычисленных значений руками.
- Листы создавай через `modify_workbook_structure`; пиши через `set_cell_range` построчно. `value` — только примитивы (строка/число/булево); формулы — полем `formula` (или строкой, начинающейся с `=`).
- Если пользователь не дал цифры — бери примерные (срок 5 лет, платёж 100 000, ставка 5%, начало 01.01.2026, отчётная дата 31.12.2026) и напиши одной строкой в чате, что ячейки входные и их можно поменять.

## Лист «Параметры»

| Ячейка | Содержимое | Тип |
|---|---|---|
| A1 | МСФО (IFRS) 16 — Параметры аренды | текст, bold |
| A3 / B3 | Дата начала аренды / 01.01.2026 | дата (входная) |
| A4 / B4 | Срок аренды, лет / 5 | число (входное) |
| A5 / B5 | Годовой платёж / 100000 | число (входное) |
| A6 / B6 | Платежей в год (1, 2, 4, 12) / 1 | число (входное) |
| A7 / B7 | Годовая ставка дисконтирования / 0.05 | число (входное), формат 0.00% |
| A8 / B8 | Платежи: «конец» или «начало» периода / конец | текст (входное) |
| A9 / B9 | Первоначальные прямые затраты / 0 | число (входное) |
| A10 / B10 | Отчётная дата / 31.12.2026 | дата (входная) |
| A11 / B11 | Ставка за период | формула: `=(1+B7)^(1/B6)-1` |
| A12 / B12 | Всего периодов | формула: `=B4*B6` |
| A13 | Синие ячейки — входные данные, можно менять | примечание |

Входные ячейки (B3–B10): синий шрифт `#0000FF`, светло-жёлтая заливка `#FFFF99`. Формулы и заголовки — чёрным. Числа — формат `#,##0.00`, даты — `DD.MM.YYYY`.

## Лист «График»

Строка 1: заголовок «График аренды» (bold).
Строка 3 — шапка (bold): `A: Период | B: Дата | C: Платёж | D: Проценты | E: Погашение обязательства | F: Обязательство на конец | G: Амортизация ROU | H: ROU на конец`.

Строка 4 — период 0 (начало аренды):

| Ячейка | Формула/значение |
|---|---|
| A4 | `0` |
| B4 | `='Параметры'!$B$3` |
| C4, D4, E4, G4 | `0` |
| F4 | платежи в конце периода: `='Параметры'!$B$5*(1-(1+'Параметры'!$B$11)^-'Параметры'!$B$12)/'Параметры'!$B$11`; в начале периода: то же умножить на `(1+'Параметры'!$B$11)` |
| H4 | `=F4+'Параметры'!$B$9` |

Строки 5 и далее — периоды k = 1..B12 (каждая строка отдельным вызовом; для строки r, предыдущая r−1):

| Ячейка | Формула |
|---|---|
| A r | `=A(r-1)+1` |
| B r | `=EDATE('Параметры'!$B$3,A r*12/'Параметры'!$B$6)` |
| C r | `='Параметры'!$B$5` |
| D r | платежи в конце периода: `=F(r-1)*'Параметры'!$B$11`; в начале периода: `=(F(r-1)-C r)*'Параметры'!$B$11` |
| E r | `=C r-D r` |
| F r | `=F(r-1)-E r` |
| G r | `=$H$4/'Параметры'!$B$12` |
| H r | `=H(r-1)-G r` |

Последняя строка после графика — контрольная: суммы по C, D, E, G и проверка `=ROUND(F(последняя),2)` — должно быть 0. Если не 0 — в формулах ошибка, исправь до показа результата пользователю.

## Лист «Отчётная дата»

| Ячейка | Содержимое |
|---|---|
| A1 | МСФО (IFRS) 16 — Показатели на отчётную дату (bold) |
| A3 / B3 | Отчётная дата / `='Параметры'!$B$10` |
| A5 | БАЛАНС (bold) |
| A6 / B6 | Обязательство по аренде, всего / `=INDEX('График'!$F:$F,MATCH($B$3,'График'!$B:$B,1))` |
| A7 / B7 | — краткосрочная часть (12 мес) / `=SUMIFS('График'!$E:$E,'График'!$B:$B,">"&$B$3,'График'!$B:$B,"<="&EDATE($B$3,12))` |
| A8 / B8 | — долгосрочная часть / `=B6-B7` |
| A9 / B9 | Актив права пользования (ROU) / `=INDEX('График'!$H:$H,MATCH($B$3,'График'!$B:$B,1))` |
| A11 | ПРИБЫЛИ И УБЫТКИ — с начала аренды по отчётную дату (bold) |
| A12 / B12 | Амортизация ROU / `=SUMIFS('График'!$G:$G,'График'!$B:$B,"<="&$B$3)` |
| A13 / B13 | Проценты по обязательству / `=SUMIFS('График'!$D:$D,'График'!$B:$B,"<="&$B$3)` |

Примечания:
- Отчётная дата должна быть не раньше даты начала аренды (иначе MATCH найдёт шапку — в этом случае выведи 0 и предупреди).
- `MATCH(...,1)` корректен: даты в Графике отсортированы по возрастанию.

## Порядок работы

1. Спроси цифры, только если пользователь не дал ни одной и запрос выглядит разовым уточнением; иначе строй с примерными и объяви их одной строкой.
2. Создай три листа (`modify_workbook_structure`).
3. Заполни «Параметры», затем «График» (строка 4, потом каждую строку k), затем «Отчётная дата».
4. Проверь контрольную строку графика (F последнего периода = 0).
5. В чате — краткий итог: обязательство на отчётную дату (всего/кратк./долгосроч.), ROU, расходы периода. Ссылки на ячейки вида [B6]('Отчётная дата'!B6).
